One-time setup in Chrome or Edge

  1. Download the browser helper and extract the ZIP to a folder you will keep.
  2. Open chrome://extensions or edge://extensions. Turn on Developer mode, choose Load unpacked, and select the extracted folder containing manifest.json.
  3. Open this page in that same browser, reload it, then click Connect and start below.

The helper can read eBay search pages and connect to Dealfinder at 127.0.0.1:8000. It does not read cookies or passwords, place bids, buy items, or send data to other servers.

Install the helper and reload this page to connect.

If eBay asks for verification, the helper stops and keeps its tab open. Complete verification there, then click Connect and start again. Pause in the header pauses automatic collection too.
