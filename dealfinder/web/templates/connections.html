Browser search helper

Connect eBay and HiBid once. The helper rotates catalog searches in one background tab every 30 seconds, collecting listings without manual imports. Keep this PC, Dealfinder and your browser running.

Install or update the helper, then reload this page in Chrome or Edge.

Install or update the helper · version 1.2
  1. Download the helper and extract it into your existing helper folder.
  2. Open edge://extensions or chrome://extensions, enable Developer mode, then choose Load unpacked and select that folder. If already installed, click its Reload button and approve the new HiBid permission.
  3. Reload this page in that browser and click Connect both sites.

Version 1.1 only reads eBay; update to 1.2 to enable HiBid. No browser cookies, passwords, bids or purchases are read or submitted.
